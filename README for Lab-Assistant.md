# 🤖 Lab-Assistant — Perplexity Inspired

A full-stack AI-powered chat web application inspired by Perplexity.ai. Users can chat with AI models in real-time, with persistent chat history, titles, and full authentication.

## ✨ Features

- 🔐 **Authentication** — Signup, Login with Email Verification (Nodemailer)
- 🤖 **AI Chat** — Chat with AI models powered by LangChain
- ⚡ **Real-time Messaging** — Instant responses using Socket.io
- 💬 **Chat History** — All chats saved with auto-generated titles
- 🎨 **Clean UI** — Responsive design built with Tailwind CSS
- 📦 **State Management** — Redux for global state handling
